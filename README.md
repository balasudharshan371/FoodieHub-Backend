# FoodieHub Backend ??

Full-Stack Online Food Ordering and Restaurant Management System - Spring Boot Backend.

## Technologies
- Java 21 (LTS)
- Spring Boot 3.3.4
- Spring Security + JWT Stateless Authentication
- Spring Data MongoDB
- Jakarta Bean Validation
- Maven & Lombok
- OpenAPI / Swagger Documentation (`/swagger-ui.html`)

## Getting Started
```bash
# Configure environment variables in application.yml or environment:
# MONGODB_URI=mongodb://localhost:27017/foodiehub
# JWT_SECRET=your_jwt_secret

mvn clean spring-boot:run
```
